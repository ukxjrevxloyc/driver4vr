## 🤖 Overview

Driver4VR adds full body tracking to SteamVR using a Kinect sensor, smartphones, or webcams, providing hip, knee, and foot trackers for VRChat and VR fitness.

Whether you're a newcomer or a veteran, Driver4VR provides the tools you need to get the most out of your ai tools experience. Designed for Windows and macOS, it delivers a seamless, high-performance workflow.

## ✨ Key Features

| Feature | Description |
|---|---|
| **Kinect Support** | Uses Kinect v1 and v2 for precise skeleton body tracking |
| **Phone Trackers** | Smartphones act as individual joint trackers via the app |
| **Webcam Tracking** | AI pose estimation for lower body from a single webcam |
| **SteamVR Compatible** | Appears as standard SteamVR trackers for any supporting game |
